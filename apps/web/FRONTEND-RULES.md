# Celestea Studio · 前端渲染铁律（FRONTEND-RULES）

> 本文件为 Celestea-Studio 前端（**`apps/web/`**，TypeScript + Vite）的**验收硬性标准**。
> ⚠️ **本文件的「铁律 N」与 `docs/AGENT.md` 的铁律是两套独立编号**（内容毫不相关：那边 1 号是「跑全量门禁」，
> 这边 1 号是「禁止先清空后加载」）。在别处引用时请写清是**前端铁律 N**。
> 所有后续前端 worker 必须遵守；违反以下任一铁律 = 验收不过。

## 铁律

1. **禁止「先清空后加载」**
   任何可见区域刷新内容时，禁止先 `innerHTML = ''` / 清空容器再逐条渲染（会产生空白帧）。
   一律**离屏构建**（`document.createElement('div')` 等不挂载容器内完整构建）+ **单次替换**
   （`container.replaceChildren(...off.childNodes)`），旧内容保持可见直到新内容就绪。

2. **树 / 列表刷新禁止整树 innerHTML 重建**
   会话树、提供商列表等层级列表刷新时，禁止整树 `innerHTML` 重建。必须：
   - 局部增量更新（如 worker 组轮询只更新该组）；或
   - 双缓冲 + 一次性替换，并**恢复展开状态**（记录 `details.open`）与输入焦点。

3. **切换类操作必须防竞态**
   会话切换、pane 切换等异步操作必须带**竞态守卫**（序号 `seq` 递增 + 结果返回时校验
   `seq === 当前`），晚到的旧请求结果一律丢弃，不得覆盖新状态；加载期间只显示轻量指示
   （顶部细进度条 / 状态栏文案），绝不整页空白。

4. **折叠 / 展开不得重建 DOM、不得丢状态**
   可折叠区域（工作区节点等）的展开/收起**禁止删除重建子节点**，也**不得丢失状态**
   （焦点 / 选中 / 展开位置 / 滚动位置）；选中态只切 class，不重渲染。
   动效怎么实现不限（class + CSS transition、JS 驱动都可以），**但必须能按 ⑩ 关掉**。
   > 为什么不再点名 CSS transition：那是**选定实现**。本轮的「回到底部」用 JS 逐帧重算，
   > 完全符合本条的精神（不重建、不丢状态）却按字面违反 —— 见铁律 11「守后果不守机制」。

5. **弹窗打开 / 关闭不触发背景视图重渲染**
   modal / 浮层 / 菜单的打开与关闭不得触发其下层背景视图的刷新或重建。

6. **轮询只做局部更新**
   定时轮询（如引擎 Worker 组）只能更新发生变化的局部区域，禁止整页/整树重绘。

7. **设置页 pane 切换零重建**
   左导航切页只切换 class；页面内容首次加载后缓存，切回不重新请求、不重建
   （数据刷新仅由「重新载入」或打开设置页等显式动作触发）。

8. **新增 UI 一律沿用本套纪律**
   任何新增可见区域/组件（含工具卡、信息块、树、列表、弹窗）默认采用上述模式；
   新增 `innerHTML` 赋值前必须自问：是否可以离屏构建后单次替换？

9. **异步更新不得移动用户的视口位置**
   流式追加、轮询、局部替换**都不得**改变用户当前的滚动位置 —— 用户正在读上面时，
   新内容进来不许把他拽回底部；贴着底部时才跟随（且要**每一帧跟着内容重算**，
   不是开始时算一次落点）。「回到底部」这类控件必须**跟着还在增长的内容**走到真底。
   > 依据：本轮 A/B 实测 —— 某臂在流式期间**冻结落点** ⇒ 停在中途，而它 13 条真机断言全 PASS。

10. **动画必须尊重 `prefers-reduced-motion`**
    任何动效（含 JS 平滑滚动）在用户声明减少动态效果时必须降级为**一步到位**。
    只有一个真源：`src/ui/viewport.ts`（不要各处自己 `matchMedia`）。

11. **长内容的 DOM 必须可裁剪，裁剪必须同时释放堆引用**
    长会话/长列表按上限裁剪节点时，必须**同时**释放它在堆里的引用与监听器；
    只管绘制不管堆 ⇒ 内存不降、越用越卡。见 `src/ui/messages/dom-cap.ts`。

## 验收口径

- 人工/自动化验收时逐项核对上述铁律；出现「空白帧」「整树闪动」「旧结果覆盖新状态」
  任一现象即视为违反。
- **前端自己的构建必须过**：`pnpm --dir apps/web run build`（`tsc --noEmit` 严格模式 + `vite build`）。
  ⚠️ **不要用根 `pnpm build` 来"验证前端"** —— 它是 `pnpm -r --filter "!celestea-studio-frontend" build`，
  **显式排除前端**，跑了等于没验证。（2026-10-04 更正：本文原先点名的就是这条命令。）
  全量门禁里的前端那一道是 `pnpm check:web`（= `scripts/build-webdist.mjs` + `pnpm --dir apps/web run check`）。
- 后端契约未就绪时允许优雅降级，但不允许以「加载中…」占位整区替换作为常规路径
  （首次空容器除外，且完成后必须单次替换）。
